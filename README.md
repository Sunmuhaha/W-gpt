### ภาพรวม
โปรเจกต์นี้เป็นโปรเจกต์ที่สร้างขึ้นเพื่อการศึกษา เพื่อให้ผู้ใช้งานรับรู้ถึงด้านมืดของเทคโนโลยีปัญญาประดิษฐ์(AI)และทดลองใช้งาน

### การนำไปใช้ แก้ไข ดัดแปลง
โปรเจกต์ WormGPT นี้เป็นโปรเจกต์ **Open Source** ประเภท **Public Domain**(ทรัพย์สินสาธารณะ) หมายความว่าคุณหรือใครก็ตามสามารถนำ Source Code ของเราไป**ใช้,แก้ไข,ดัดแปลง หรือกระทำการใดๆ ก็ตาม**ได้โดย**ไม่จำเป็นต้องได้รับอนุญาต**

### เกี่ยวกับโมเดล
โมเดล WormGPT เป็นโมเดลที่ดัดแปลงจาก **Qwen 3.8 flash** โดยเป็นการกำหนด Persona ให้กับโมเดลในการกระทำการให้ใกล้เคียงกับ WormGPT *(การ Jail break)* โดยหาก Qwen 3.8 flash ใช้งานไม่ได้หรือไม่พร้อมใช้งานจะทำการเลือกไปใช้ **Gemini 3.5 flash-lite** โดยอัตโนมัติ(*fallback*) โมเดลของเราขับเคลื่อนบนแพลตฟอร์ม Botpress(*https://botpress.com/*)

### การปัดความรับผิดชอบ
โดยหากคุณนำคำตอบจากโมเดลของเราไปใช้

1.โจมตีเครื่องคอมพิวเตอร์แม่ข่าย(Server),เครื่องคอมพิวเตอร์ลูกข่าย(Client),ฐานข้อมูล(Database) เป็นอันก่อให้เกิดความเสียหาย

2.สร้างความเสียหายแก่ผู้อื่น รวมทั้งด้านเทคโนโลยี จิตใจ ทรัพย์สินและทุกด้านที่เกี่ยวข้อง

3.โจรกรรมทางข้อมูล(ทุกประเภท)

4.และทุกด้านที่ก่อให้เกิดความเสียหายแก่ผู้อื่น

เราจะ**ไม่รับผิดชอบใดๆทั้งนั้น**แก่ความเสียหายที่คุณก่อขึ้น
